   • Tokens are simple (not cryptographically secure)
   • For production: Implement proper hashing & JWT
   • SSL/TLS is required for production

⚠️  Game Client Installation
   • Must be installed at: C:\Program Files (x86)\Wonderland Online\
   • If different: Update game_launcher.py line 15
   • Verify Wonderland.exe exists before playing

⚠️  Network Requirements
   • Port 8090 must be available (registration server)
   • Port 5423 must be reachable (game server)
   • HTTPS certificate required for production
   • Firewall must allow outbound connections to 5423

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Python not found
Solution: Install Python 3 from python.org, add to PATH

Problem: Port 8090 already in use
Solution: Close other apps, or change port in registration_server.py

Problem: Game client not found
Solution: Install to C:\Program Files (x86)\Wonderland Online\

Problem: Can't connect to wlo.kiaoragaming.xyz:5423
Solution: Check internet, firewall, or server status

Problem: Game won't launch
Solution: Check game_launcher.py errors, verify client path

Problem: Web pages show 404
Solution: Run SETUP_AND_TEST.bat to copy files
