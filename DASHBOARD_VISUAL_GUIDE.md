## Feature Interactions

### Create Character Flow
```
1. User clicks "Create Character"
   ↓
2. Form appears with all fields
   ↓
3. User fills in:
   - Name (with validation)
   - Class (dropdown)
   - Race (dropdown)
   - Gender (dropdown)
   - Skin (color picker)
   ↓
4. Preview updates live
   ↓
5. User clicks "Create Character"
   ↓
6. Validation checks:
   - Name 3-20 chars ✓
   - Only alphanumeric + underscore ✓
   - Name not duplicate ✓
   - All fields filled ✓
   ↓
7. Character added to list
   ↓
8. Success message shown
   ↓
9. Form closes
   ↓
10. Character card appears
```

### Delete Character Flow
```
1. User clicks [Delete] button
   ↓
2. Confirmation popup:
   "Are you sure you want to delete [CharName]?
    This cannot be undone!"
   ↓
3a. User clicks "OK"
    → Character deleted
    → Success message shown
    
3b. User clicks "Cancel"
    → Nothing happens
    → Form closes
```

### Login Flow
```
1. User goes to http://localhost:8090
   ↓
2. Sees registration page
   ↓
3. Clicks "Login" tab
   ↓
4. Fills username/password
   ↓
5. Clicks "Login to Dashboard"
   ↓
6. Server verifies credentials
   ↓
7. Token generated and returned
   ↓
8. Token stored in localStorage
   ↓
9. Auto-redirects to dashboard.html
   ↓
10. Dashboard checks token
   ↓
11. User interface loads
```

  skin: "light",
  level: 1,
  experience: 0,
  gold: 0,
  createdAt: "2024-01-04T..."
}
        ↓
Saved to localStorage:
localStorage.setItem(
  'userCharacters_testuser123',
  JSON.stringify([character])
)
        ↓
Auto-saved Every 60 Seconds:
setInterval(saveCharacters, 60000)
        ↓

- User clears localStorage
